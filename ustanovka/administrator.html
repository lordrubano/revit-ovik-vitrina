Пульт ОВиК: что это с точки зрения ИТ

Надстройка для Autodesk Revit. Не серверная программа: библиотека внутри процесса Revit на том компьютере, где он запущен. Серверы моделей и лицензий она не трогает. Надстройка ещё не выпущена; описан проект установки. Пометки: проектное решение — так мы её делаем; вывод из документации — вывод по устройству механизма; проверим на пилоте — в источниках не подтверждено.

Что это

  • Тип. Управляемая .NET-сборка (DLL), которую Revit загружает по манифесту .addin; точки входа — IExternalApplication (старт и выход Revit) и IExternalCommand (вызов команды). Отдельного процесса, службы, драйвера или порта механизм не создаёт (документация Autodesk, «Deployment Options», «Add-in Registration»).
  • Версии Revit и .NET. 2024 — .NET Framework 4.8; 2025 — .NET 8; 2026 — .NET 8 (в требованиях для 2026.5 и позже указан .NET 10; что меняется для надстроек — проверим на пилоте); 2027 — .NET 10 (только Windows 11). Под каждую версию своя сборка; установщик ставит нужную. Revit LT надстройки не поддерживает.
  • Подпись. проектное решение Authenticode (SHA-256), коммерческий сертификат общедоступного центра сертификации (не самоподписанный), с меткой времени. Проверить: свойства файла → вкладка «Цифровые подписи» или PowerShell Get-AuthenticodeSignature <путь к DLL>. В манифесте полный путь к библиотеке.

проектное решение Библиотека и таблицы: «для себя» — %AppData%\Autodesk\Revit\Addins\<год>\PultOVIK\ (рядом с манифестом); «для всех» — C:\Program Files\PultOVIK\<год>\ (вне профиля; манифест — в общей папке надстроек версии). Для AppLocker: папка AppData правилами DLL по умолчанию не разрешена, Program Files — разрешена.

  • В Revit 2027 общая папка в ProgramData не читается; используется Program Files\Autodesk\Revit\Addins\2027. Установка Revit эту папку не создаёт (по сообщениям на форуме Autodesk) — установщик создаёт её сам. Установка «для всех» под 2027 — проверим на пилоте. В справке Autodesk путь записан «Addins\Revit 2027», на деле папка называется «Addins\2027».
  • Тихая установка (планируемый вид): msiexec /i PultOVIK.msi /qn ALLUSERS=1; добавить /norestart при необходимости. проектное решение Имя файла условное. Удаление: msiexec /x PultOVIK.msi /qn или «Удаление программ». Раздаётся SCCM / Configuration Manager или Intune. Не путать образ развёртывания Autodesk (сторонние надстройки в него не включаются — справка Autodesk, шаг «Extensions») и образ виртуальной машины или терминального сервера (туда ставит администратор). Инструкции Microsoft по Intune именно для надстроек Revit не искали — проверим на пилоте.
  • Что ставит: манифест, папку с библиотекой и таблицами, запись в «Удаление программ». Чего не делает проектное решение: службы, драйверы, автозагрузка, задания планировщика, сетевые порты, изменения в Revit и его настройках (в том числе Revit.exe.config), изменения на серверах.
  • Проверка «до и после» на тестовой машине: список файлов в папках надстроек и Program Files; службы (services.msc); автозагрузка и планировщик заданий; ветки реестра Run и записи установщика. Разница должна быть только в перечисленном выше.

Сеть, данные, серверы, лицензии

  • Сеть. проектное решение Порты не открываются, интернет для работы не нужен. Ключ активации нашего продукта включается без интернета; обновления по желанию. ИИ-модуля в первой версии нет; если появится — отдельный, по умолчанию выключен, включает ИТ, данные при включении уходят в выбранный ИИ-сервис.
  • Данные. проектное решение Модель не покидает компьютер, расчёт локальный. Сетевой путь к библиотеке (\\server\share) не используется: файлы копируются локально. Для Revit 2025–2027 такая загрузка у Autodesk не описана — проверим на пилоте, если вашей схеме нужна общая папка. В модель надстройка добавляет свои параметры (где нет подходящих ADSK) — после синхронизации их видят все; согласовать с BIM-менеджером; свои — с префиксом, по возможности ADSK (проектное решение).
  • Совместная работа. Файловая модель, Revit Server, облако Autodesk — как обычно: правки надстройки — это правки пользователя в его сеансе Revit, в центральную модель они попадают обычной синхронизацией. Серверной части у надстройки нет (вывод из документации; прямой фразы Autodesk нет).
  • Лицензии. Надстройка не зависит от сервера лицензий и типа лицензии Revit (вывод из документации: механизм загрузки не обращается к лицензированию; прямого текста Autodesk нет).

Варианты и политики

  • Citrix / RDS / VDI. Ставит администратор один раз на сервер или в образ виртуальной машины, «для всех»: манифест — в общую папку, библиотека — в C:\Program Files\PultOVIK\<год>\ (вне профиля). Установка «на пользователя» в AppData\Roaming увеличивает перемещаемый профиль (наш вывод, у Autodesk отдельного текста нет). Сам Revit: в требованиях 2026 и 2027 таблиц Citrix и VMware нет (в 2024 были); раздел справки «Configuring Autodesk Revit for Citrix» остаётся; Autodesk не даёт заверений по виртуальным средам и не поясняет, значит ли это прекращение поддержки. Страницы про Microsoft RDS и Azure Virtual Desktop не найдено — проверим на пилоте.
  • AppLocker. Правила для DLL по умолчанию выключены; если включены, для библиотеки нужно разрешающее правило. Разрешение по издателю (подпись) — путь, который рекомендует Microsoft. Правила по умолчанию пускают %programfiles% и %windir%, но не AppData и ProgramData. Поведение с .NET-библиотекой внутри Revit отдельно не описано — проверим на пилоте.
  • App Control (WDAC). Разрешение по издателю — отдельной дополнительной (supplemental) политикой; при включённом «Dynamic Code Security» политика применяется и к библиотекам, загружаемым .NET, в том числе с сетевой папки.
  • Окно безопасности Revit. Без подписи: «Всегда загружать / Загрузить один раз / Не загружать»; запоминается только «Всегда загружать», после обновления библиотеки окно может появиться снова. С подписью — показывается издатель и запоминается он: обновления проходят без окна (главный довод за подпись). Заранее убрать окно: разослать сертификат издателя групповой политикой (по словам сотрудника Autodesk; в справке нет) — проверим на пилоте, в какое хранилище (пользователя или компьютера).
  • Как быстро отключить без удаления. (Admin) Add-Ins Manager (Revit 2025.4 и новее): «всегда отключена» для надстройки или запрет всех сторонних, кроме списка доверенных; результат — файл AdminSettings.json: до 2026 включительно — C:\ProgramData\Autodesk\RVT <год>\Admin\, в 2027 — C:\Program Files\Autodesk\Revit\Admin\2027\; права на файл настраивает администратор, чтобы пользователи не могли его менять. Убирает ли «всегда включена» окно безопасности — проверим на пилоте. Либо убрать или переименовать манифест .addin: Revit читает манифесты при запуске (вывод из документации).

Что проверим на пилоте

  • Revit 2027: манифест в Program Files\Autodesk\Revit\Addins\2027, подписанная и неподписанная надстройка.
  • Revit 2026.5 и позже: что меняется для надстроек (.NET 10).
  • Сетевой путь к библиотеке в Revit 2025–2027 (только если нужна общая папка).
  • Сертификат издателя: исчезает ли окно безопасности, в какое хранилище класть.
  • «Всегда включена» в (Admin) Add-Ins Manager как замена окна.
  • Включены ли проверка DLL (AppLocker) или Dynamic Code Security (App Control) на рабочих станциях; какое правило нужно.
  • Citrix / RDS: где лежат манифест и библиотека; размер перемещаемого профиля.
