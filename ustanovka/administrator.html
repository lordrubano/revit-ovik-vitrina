Пульт ОВиК: что это с точки зрения ИТ

Надстройка для Autodesk Revit — библиотека внутри процесса Revit на том компьютере, где он работает; серверы моделей и лицензий не трогает. Ещё не выпущена: описан проект установки. Пометки: проектное решение — так мы её делаем; вывод из документации — вывод по устройству механизма; проверим на пилоте — в источниках не подтверждено. Главный вопрос — где работает Revit. Проверка для пользователя — на своём компьютере: свернуть окно удалённого подключения, правой кнопкой на панели задач → «Диспетчер задач» (Ctrl+Shift+Esc в полноэкранном удалённом окне открывает Диспетчер задач удалённой машины); вкладка «Процессы»: есть отдельная строка Autodesk Revit — Revit на этом компьютере (группа 1); Revit отдельно не виден, а есть программа подключения (Citrix Workspace (в Диспетчере задач — Citrix HDX Engine), «Подключение к удалённому рабочему столу», Windows App, Omnissa (VMware) Horizon Client, AnyDesk, TeamViewer или браузер) — Revit работает у компании (группа 2); окно Revit внутри программы подключения — не «строка Revit». На Mac — «Мониторинг системы»; Revit в Windows внутри Parallels — вариант 1.4.

Что это

  • Тип. Управляемая .NET-сборка (DLL), которую Revit загружает по манифесту .addin; точки входа — IExternalApplication (старт и выход Revit) и IExternalCommand (вызов команды). Отдельного процесса, службы, драйвера или порта механизм не создаёт (документация Autodesk, «Deployment Options», «Add-in Registration»). Потоки процесса действуют с правами вошедшего пользователя: для DLP надстройка выглядит как Revit.exe.
  • Версии Revit и .NET. 2024 — .NET Framework 4.8; 2025 — .NET 8; 2026 — .NET 8 (в требованиях для 2026.5 и позже указан .NET 10; что меняется для надстроек — проверим на пилоте); 2027 — .NET 10 (только Windows 11). Под каждую версию своя сборка; установщик ставит нужную. Revit LT надстройки не поддерживает.
  • Подпись. проектное решение Authenticode (SHA-256), коммерческий сертификат общедоступного центра сертификации (не самоподписанный), с меткой времени. Проверить: свойства файла → вкладка «Цифровые подписи» или PowerShell Get-AuthenticodeSignature <путь к DLL>. В манифесте полный путь к библиотеке.

Во всех вариантах данные с сервера компании из-за надстройки никуда не уходят: она ничего не отправляет проектное решение. Администратор обязательно — в вариантах 2.2, 2.4, 2.5 и в 2.6 для общих облачных столов, при централизованной установке и строгих политиках запуска; в 2.1, 2.3 и для личного облачного ПК (2.6) — как на обычном компьютере. Условия поверх любого варианта: централизованная установка (образ развёртывания Autodesk сторонние надстройки не включает; образ виртуальной машины — включает), строгие политики запуска, DLP, перемещаемые профили, место хранения моделей.

проектное решение Библиотека и таблицы: «для себя» — %AppData%\Autodesk\Revit\Addins\<год>\PultOVIK\ (рядом с манифестом); «для всех» — C:\Program Files\PultOVIK\<год>\ (вне профиля; манифест — в общей папке надстроек версии). Для AppLocker: папка AppData правилами DLL по умолчанию не разрешена, Program Files — разрешена.

  • В Revit 2027 общая папка в ProgramData не читается; используется Program Files\Autodesk\Revit\Addins\2027. Установка Revit эту папку не создаёт (по сообщениям на форуме Autodesk) — установщик создаёт её сам. Установка «для всех» под 2027 — проверим на пилоте. В справке Autodesk путь записан «Addins\Revit 2027», на деле папка называется «Addins\2027».
  • Тихая установка (планируемый вид): msiexec /i PultOVIK.msi /qn ALLUSERS=1; добавить /norestart при необходимости. проектное решение Имя файла условное. Удаление: msiexec /x PultOVIK.msi /qn или «Удаление программ». Раздаётся SCCM / Configuration Manager или Intune. Инструкции Microsoft по Intune именно для надстроек Revit не искали — проверим на пилоте.
  • Что ставит: манифест, папку с библиотекой и таблицами, запись в «Удаление программ». Чего не делает проектное решение: службы, драйверы, автозагрузка, задания планировщика, сетевые порты, изменения в Revit и его настройках (в том числе Revit.exe.config), изменения на серверах.
  • Проверка «до и после» на тестовой машине: список файлов в папках надстроек и Program Files; службы (services.msc); автозагрузка и планировщик заданий; ветки реестра Run и записи установщика. Разница должна быть только в перечисленном выше.

Сеть, данные, серверы, лицензии

  • Сеть. проектное решение Порты не открываются, интернет для работы не нужен. Ключ активации нашего продукта включается без интернета; обновления по желанию. ИИ-модуля в первой версии нет; если появится — отдельный, по умолчанию выключен, включает ИТ, данные при включении уходят в выбранный ИИ-сервис.
  • Данные. проектное решение Модель не покидает компьютер, на котором работает Revit; расчёт локальный. Сетевой путь к библиотеке не используется: файлы копируются локально; для Revit 2025–2027 загрузка с сетевого пути у Autodesk не описана — проверим на пилоте. В модель надстройка добавляет свои параметры (где нет подходящих ADSK) — после синхронизации их видят все; согласовать с BIM-менеджером; по возможности ADSK, свои — с понятным префиксом (проектное решение).
  • Совместная работа. Файловая модель, Revit Server, облако Autodesk — как обычно: правки надстройки — это правки пользователя в его сеансе Revit, в центральную модель они попадают обычной синхронизацией. Серверной части у надстройки нет (вывод из документации; прямой фразы Autodesk нет). Локальные копии и кэш облачных моделей существуют на компьютере, где работает Revit, независимо от надстройки.
  • Лицензии. Надстройка не зависит от сервера лицензий и типа лицензии Revit (вывод из документации: механизм загрузки не обращается к лицензированию; прямого текста Autodesk нет).

Политики и виртуальные среды

  • Виртуальные среды. В вариантах 2.2, 2.4, 2.5 и в 2.6 для общих облачных столов обязательно ставит администратор — один раз на сервер, в образ виртуальной машины или слой приложений, «для всех»: манифест — в общую папку, библиотека — в C:\Program Files\PultOVIK\<год>\. Варианты 2.1, 2.3 и личный облачный ПК (2.6) — как обычный компьютер; надёжнее — в образ. Установка «для себя» на столе из пула не годится: стол сбрасывается. Сам Revit: в требованиях 2024 (и, по копии таблиц у партнёра, 2025) таблицы Citrix и VMware были; в 2026 и 2027 их нет — значит ли это прекращение поддержки, Autodesk не поясняет. Раздел справки про Citrix остаётся. Кроме того, Autodesk не даёт заверений по виртуальным средам и поддерживает программу, но не среду виртуализации. Для RDS, Azure Virtual Desktop, Windows 365 отдельных страниц Autodesk нет — проверим на пилоте.
  • AppLocker. Правила для DLL по умолчанию выключены; если включены — нужно разрешающее правило; рекомендация Microsoft — по издателю (подпись). Правила по умолчанию пускают %programfiles% и %windir%, но не AppData и ProgramData. Поведение с .NET-библиотекой внутри Revit отдельно не описано — проверим на пилоте. App Control (WDAC): разрешение по издателю удобнее всего оформлять дополнительной (supplemental) политикой; при «Dynamic Code Security» политика применяется и к библиотекам, которые загружает .NET.
  • Окно безопасности Revit. Без подписи: «Всегда загружать / Загрузить один раз / Не загружать»; запоминается только «Всегда загружать», после обновления окно может появиться снова. С подписью — показывается издатель и запоминается он: обновления проходят без окна. Заранее убрать окно: разослать сертификат издателя групповой политикой (по словам сотрудника Autodesk; в справке нет) — проверим на пилоте, в какое хранилище (пользователя или компьютера).
  • Как быстро отключить без удаления. (Admin) Add-Ins Manager (Revit 2025.4 и новее): «всегда отключена» или запрет всех сторонних, кроме списка доверенных; результат — файл AdminSettings.json: до 2026 — C:\ProgramData\Autodesk\RVT <год>\Admin\, в 2027 — C:\Program Files\Autodesk\Revit\Admin\2027\; права на файл настраивает администратор. Убирает ли «всегда включена» окно безопасности — проверим на пилоте. Либо убрать или переименовать манифест .addin: Revit читает манифесты при запуске (вывод из документации).

Что проверим на пилоте

  • Revit 2027: манифест в Program Files\Autodesk\Revit\Addins\2027; Revit 2026.5 и позже (.NET 10).
  • Сертификат издателя: исчезает ли окно безопасности; «Всегда включена» как замена окна.
  • AppLocker / App Control на рабочих станциях: какое правило нужно.
  • Удалённый вход: видеокарта, печать. Пул: сброс стола, слои, FSLogix.
  • Опубликованные приложения и RDS: где манифест и библиотека, размер профиля.
  • Облачные ПК: виден ли графический адаптер, драйверы.
  • Личный ноутбук: что остаётся на диске; Mac: Windows 11 на Arm.
  • Ноутбук вне офиса: модель по VPN и без него; раздача вне сети. DLP: журнал под Revit.exe.
