# Revit ОВиК — витрина

Готовые страницы для просмотра в браузере.

- [Пакет для инженера: презентация, ролики, памятка, нормы](https://lordrubano.github.io/revit-ovik-vitrina/paket/) — одна страница со всем для инженера-проектировщика: интерактивная презентация, лист-памятка PDF, таблица норм и каталог оборудования.
- [Как ставится на предприятии (для инженера и администратора)](https://lordrubano.github.io/revit-ovik-vitrina/ustanovka/) — надстройка не серверная: где она живёт при разном устройстве предприятия, что кладёт на компьютер, чего не делает, где нужен администратор.
- [Пульт ОВиК — интерактивная презентация надстройки для Revit](https://lordrubano.github.io/revit-ovik-vitrina/pult/) — демо: окно Revit, расчёт воздухообмена по СП, проверка модели, 3D.
- [Плагины и ИИ для ОВиК в Revit: что правда, что реклама](https://lordrubano.github.io/revit-ovik-vitrina/otchet/) — проверка присланного обзора по первоисточникам, российские реалии, расчёты по СП, спецификации и отверстия, ИИ-помощники, план внедрения из десяти шагов.
- [Revit под российские нормы: настройка из готового и 12 инструментов, которые можно написать самим](https://lordrubano.github.io/revit-ovik-vitrina/normy/) — шаблон ADSK и расчётные плагины, обмен с экспертизой через IFC, что Revit позволяет дописать своим кодом, пилот «Воздухообмен по нормам».
